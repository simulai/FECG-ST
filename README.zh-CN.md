# FECG-ST：有限认知系统的思维状态转移机制（Research Draft v0.1，2026-11-16）

> 状态：草稿，未锁定。FECG 的一个独立研究分支，
> 暂不并入原有的能量收敛理论。
> 研究目标不是解释某个脑区如何产生思想，而是回答：
> 给定一个有限认知系统在时刻 t 的内部状态，
> 系统通过什么机制形成时刻 t+1 的新思维状态？
>
> 全稿严格分三层，**三层不能相互替代**：
>
> - **神经机制**：大脑中可能发生了什么？（对应假设，非结论）
> - **功能假设**：一个认知系统需要具备什么功能？（待检验）
> - **数学命题**：在明确假设下，能够严格推出什么？（已证 / 待证）
>
> 脑区词只出现在神经机制层，不参与任何数学论证。
> （删词测试：删掉全部脑区词后，§1–§5、§7 仍完整可操作。）

## 0. 问题与切入点

**核心问题（A，优先）：** 当前思绪如何产生下一段思绪？
即状态转移机制 S_t → S_{t+1}。
**子问题（B，A 内部必须解释）：** 为什么多个可能的思绪中，
某一个胜出？即选择机制。
**暂缓：** C（预测机制：大脑如何提前知道下一句话/下一步思维）、
D（策略切换机制：联想与逻辑推理之间的切换）。
C 与 D 依赖 A 的答案，另立分支（FECG-PD、策略切换）。

**三个易混问题，事先分开：**
A（下一思绪的候选内容从哪里来）、B（为什么某个候选胜出）、
C（如何把思绪变成下一句话）。语言产生 ≠ 思想产生：
想法完整却找不到词、说话流畅却无严密推理，都是反例。
本稿只研究 A（含 B 作为子问题），语言产生只作为输出层提及。

## 1. 什么是思维状态

**定义 1（认知状态）。** 设认知模型状态为

S_t = (X_t, G_t, M_t, H_t)

| 变量 | 定义 | 作用 |
|---|---|---|
| X_t | 当前活动表征 | 当前正在处理的内容 |
| G_t | 当前目标与约束 | 决定思维方向 |
| M_t | 可访问的记忆状态 | 提供历史信息和关联 |
| H_t | 当前认知活动的历史摘要 | 保留近期状态和转移信息 |

S_t 不是整个大脑的物理状态，而是选定的认知模型状态。
例如：X_t =「小脑参与预测」，G_t =「解释下一段思绪如何产生」，
M_t = {小脑、额叶、预测、注意力}。

**假设 H0（有限有效表征，待检验，非事实）。**
对于某个指定任务，可以用有限维、有限精度的状态表示来近似
其相关动力学。这不是说大脑只有有限个神经元状态；
它是本分支的工作假设，需要检验，不能直接作为普遍事实。

**反循环定义注记。**「思维状态就是当前正在思考的内容」
不提供数学信息，故不用作定义。定义 1 的内容是四个分量
的取值与取值空间，而非“正在想什么”这句空话。

## 2. 最小三阶段模型（功能假设层）

不直接写 S_{t+1} = F(S_t)——那会把竞争与选择隐藏起来。
拆成三个过程（不一定在大脑中严格串行，可能并行、交互、迭代；
作为最小数学分解，它们有研究价值）：

**阶段 A：候选生成（Generation）。**

C_t ~ Q_θ(C | S_t)，C_t = {c_1, …, c_n}，1 ≤ n ≤ K。

候选可以是概念、判断、记忆片段、问题、行动方案或思维策略。
Q_θ 表达当前状态对候选空间的影响。
候选是检索还是组合产生，**暂不决定**，作为可竞争的模型：

- Q_retrieval(c | S_t)：从记忆中检索；
- Q_composition(c | S_t, M_t)：由当前状态与记忆组合产生。

**阶段 B：竞争选择（Selection）。**

c*_t ~ Π_φ(c | C_t, S_t)。

得分分解（功能模型，非已发现的大脑公式）：

R_i = w_a A_i + w_g G_i + w_p P_i + w_v V_i

| 因素 | 含义 |
|---|---|
| A_i | 与当前状态的关联程度 |
| G_i | 与当前目标的匹配程度 |
| P_i | 对后续状态的预测价值 |
| V_i | 当前系统对该候选的价值评估 |

最简单的选择机制（softmax）：

P(c_i | C_t, S_t) = e^{β R_i} / Σ_j e^{β R_j}，β 控制选择的确定性。

数值核对（得分 3、2、1，β = 2.0）：
e^6、e^4、e^2 之比 → p ≈ 86.7%、11.7%、1.6%。
β 小时选择分散，β 大时高得分候选占优。
（该数值为模型演示，不代表真实脑活动数据。）

**阶段 C：状态稳定与更新（Stabilization）。**

S_{t+1} = U(S_t, c*_t, ξ_t)，ξ_t 为随机扰动或未建模输入。

关键性质：Q(C_{t+1} | S_{t+1}) ≠ Q(C_t | S_t)——
新思绪改变下一轮候选生成的条件，形成递归过程。

## 3. 可证明的命题（数学命题层，已核对）

设状态空间 S 有限；每个状态最多产生 K 个候选；
Q、Π 为概率分布；U 在给定 ξ 下确定。

**命题 P1（状态转移概率的存在性）。** 定义

T(s, s') = Σ_C Q(C | s) Σ_{c∈C} Π(c | C, s) 1[U(s, c) = s']。

则 T(s, s') ≥ 0 且 Σ_{s'} T(s, s') = 1，
故系统可表示为有限状态马尔可夫链。

*证明。* 非负性由 Q、Π 的非负性得来。
对 s' 求和：Σ_{s'} 1[U(s,c) = s'] = 1（U 确定唯一下一状态），
故 Σ_{s'} T = Σ_C Q(C|s) Σ_{c∈C} Π(c|C,s) = 1。∎

*口径澄清 P1′。* §2 的 U 含噪声 ξ_t，而 P1 的 U 不含 ξ。
P1 在“ξ 固定”的情形下成立；一般情形须取 ξ-边际：

T(s, s') = Σ_C Q(C|s) Σ_{c∈C} Π(c|C,s) E_ξ[1[U(s,c,ξ) = s']]。

结论不变，证明同上（期望的线性性）。此为澄清，非修正。

*限定：* P1 只证明该机制模型构成合法的概率状态转移系统，
不证明真实大脑如此运行。

**命题 P2（选择概率与候选得分的关系）。**
p_i = e^{βR_i} / Σ_j e^{βR_j}，则

∂p_i/∂R_i = β p_i (1 − p_i)，∂p_i/∂R_j = −β p_i p_j（j ≠ i）。

故 β > 0 时：提高某候选得分提高其选择概率，
提高竞争候选得分降低其选择概率。∎（标准 softmax 求导。）

*限定：* 不能证明大脑使用 softmax，也不能证明实际候选得分
具有 §2 的四个组成部分。

**命题 P3（选择确定性极限）。** 候选数为 n：

- β → 0 时，p_i → 1/n（近似均匀选择）；
- β → ∞ 时，若存在唯一最高得分候选 c_k，则 p_k → 1，
  其余 p_i → 0（近似确定性选择）。∎

*限定：* 实际认知系统是否存在这样的统一参数 β，须实验研究。

**命题 P4（有限状态系统存在平稳分布，但不保证收敛）。**
T 为有限状态随机转移矩阵，则至少存在一个平稳分布 π，
πT = π。但存在平稳分布 ≠ 系统收敛到平稳分布。
**反例：** 两状态交替 0→1→0→1，有平稳分布 (0.5, 0.5)，
但从确定初始状态出发，分布不收敛。
唯一平稳分布与分布收敛还需不可约性、非周期性等条件。∎

*限定：* 不能把状态转移直接等同于认知收敛。
这是本分支与 FECG 能量收敛理论的分界点之一。

## 4. 三个偷渡结论的警惕点

**问题 1：候选生成是否已经假设了下一思绪？**
若 Q 直接把所有可能的下一思绪列出来，则没有解释候选如何产生。
候选生成器本身须进一步建模（Q(C | S, M)，拆成关联激活、
记忆提取、组合构造）。

**问题 2：评分函数是否只是把选择结果重新命名？**
若看到系统选了 B 就说 B 的综合得分最高，只是事后解释。
必须事先规定评分因素，并能独立测量或预测选择结果。
（§2 的 R_i 分解是待检验的功能模型，不是结论。）

**问题 3：状态是否真的足够？（最重要）**
若 P(S_{t+1} | S_t, S_{t-1}) ≠ P(S_{t+1} | S_t)，
则当前状态 S_t 不足以描述系统，须增加历史变量或更长
时间尺度的内部状态。这直接关系到有限认知与记忆连续性。
检验方式：逐步增加历史信息，看预测性能是否持续显著改善；
若存在稳定的有限维近似，则 H4（§5）成立。

## 5. 假设集 v0.1（功能假设层，待检验）

| 假设 | 内容 | 反证方向 |
|---|---|---|
| H1：状态依赖性 | 下一思绪的概率分布受当前思维状态影响，P(S_{t+1} \| S_t) | 控制历史、环境、任务后，当前状态对下一状态无额外预测信息 |
| H2：候选竞争性 | 下一思绪形成涉及多个潜在候选之间的竞争，非单一路径确定性展开 | 在操作化候选表征后，无可重复观察到的竞争或选择过程 |
| H3：状态反馈性 | 新思绪改变后续候选生成与选择概率，S_{t+1} → Q(C_{t+1} \| S_{t+1}) | 控制外部输入后，新状态对后续候选分布无可检测的影响 |
| H4：有限状态充分性 | 存在有限维状态表征，在指定任务与误差容忍度下充分预测下一思维状态 | 不断增加历史信息后预测性能仍持续显著改善，且无稳定有限维近似 |

*H2 的谨慎注记。* 大脑可能存在多个并行激活的表征，
但这不等于它们都已成为独立的候选思绪。
须区分神经活动中的潜在竞争与主观上可报告的思绪候选。

## 6. 神经机制层（对应假设，非结论）

| 功能模块 | 候选神经系统 | 当前证据边界 |
|---|---|---|
| 候选生成 | 海马体、默认模式网络、颞叶联想网络 | 参与记忆提取、内部思维及关联活动 |
| 候选表征 | 颞叶、顶叶及分布式皮层网络 | 参与语义、概念及多模态表征 |
| 目标约束 | 前额叶、ACC | 参与目标维持、冲突监测和控制 |
| 竞争门控 | 基底节—丘脑—皮层环路 | 参与认知与行为选择、门控 |
| 预测与时序调整 | 小脑及相关皮层环路 | 参与序列预测、误差学习和时序调节 |
| 语言表达 | 额颞语言网络、运动相关皮层 | 参与词汇、句法、语音和发音规划 |

*纠正两个常见误区：* 默认模式网络不只是“发呆网络”，
前额叶不是所有思维的总指挥，小脑不是单独的预测模块。
它们通过大范围皮层—皮层下环路相互作用。
目前只能提出功能对应假设，不能把 Q、Π、U 分别对应到三个脑区。
候选生成可能分布式发生，竞争选择可能在不同层级发生，
状态更新可能在多个时间尺度上进行。

*小脑的位置（本分支的判断）：* 小脑最值得研究的不是它是否
直接产生下一段思绪，而是它是否帮助整个认知系统预测当前活动
接下来可能产生的结果、并提前调整网络活动。
形式化：每个功能系统 i 对下一状态有自己的预测
Ŝ_{t+1}^{(i)} = F_i(S_t)，系统通过整合机制
S_{t+1} = Φ(Ŝ_{t+1}^{(1)}, …, Ŝ_{t+1}^{(k)}, S_t) 形成下一状态。
Φ 是待研究的抽象，不意味着大脑真有一个统一的预测汇总器；
且不能把所有预测都归因于小脑。

## 7. 瓶颈：候选思绪究竟是怎样产生的？（A/B/C 的数学可区分性）

三种竞争性解释（不一定互斥，可能在不同层级共存）：

- **A. 记忆检索模型：** c_{t+1} ~ P(M | S_t)。
  下一思绪是关联记忆被提取；思维连续性主要来自历史经验的关联传播。
- **B. 动态组合模型：** c_{t+1} = F(S_t, M_t)。
  当前状态与多个已有表征组合，形成以前没有完整出现过的新候选；
  思维具有构造性，不只是检索。
- **C. 内部预测模型：** Ŝ_{t+1} = P(S_t, θ_t)。
  系统根据当前状态和内部动力学预先形成可能的未来状态，
  其中某些预测结果进入后续思维活动。

**本节的目标：** 先不争论大脑用哪一种，而是问——
能不能构造最小模型，让三者在某些条件下产生不同的、
可以观测和反驳的下一状态分布？

设项目全集为 U（有限），记忆集 M ⊆ U。
组合代数给出可构造集 Comb(S_t, M) ⊆ U；
预测动力学给出分布 P_pred(· | S_t)，支持集记为 supp(P_pred)。

- A 的支持集 ⊆ M（下一思绪恒为已有记忆项）。
- B 的支持集 ⊆ M ∪ Comb(S_t, M)（可含新组合项）。
- C 的支持集 ⊆ supp(P_pred(· | S_t))（可含动力学外推项）。

**命题 D1（A vs B/C，支持集）。**
若观测到下一思绪 c ∉ M，则模型 A 被证伪。
（A 的支持集 ⊆ M 是定义的一部分。）

**命题 D2（B vs C，支持集分离）。**
设存在状态 S_t 使 Comb(S_t, M) 与 supp(P_pred(· | S_t)) 不同。
则对称差中的项目是可观测的区分事件：
c ∈ Comb \ supp(P_pred) 时 B 可产生、 C 赋予（近）零概率；
c ∈ supp(P_pred) \ (M ∪ Comb) 时 C 可产生、B 不能产生。
在同一 S_t 下重复观测下一思绪的经验分布，
以频率（或似然比）检验可区分 B 与 C。

*最小实例。* M = {a, b}；组合规则只允许配对 (a, b)；
习得的动力学为 a → c，其中 c ∉ M ∪ {(a, b)}。
则 A 预测下一思绪 ∈ {a, b}；B 预测 ∈ {a, b, (a, b)}；
C 预测 = c（高概率）。观测到 (a, b) 支持 B；
观测到 c 支持 C（并证伪 A、B）；只观测到 a/b 与 A 一致，
但与 B、C 的低权重分支也一致——故检验须用频率分布，
而非单次观测。

**命题 D3（坍缩条件——区分性何时消失）。**
- 若 M 在组合下封闭（∀S_t, Comb(S_t, M) ⊆ M），则 B 的支持集
  = A 的支持集，B 坍缩为 A（至多权重不同）。
- 若 P_pred 支持在 M 上且正比于关联核，则 C 退化为 A。
- 若组合规则本身定义为“取预测项再与记忆组合”，则 B 与 C
  按构造重合。
故 A/B/C 的可区分性**依赖于组合代数与预测动力学的独立固定**：
二者若事后按观测数据重定义，则任一模型都可拟合任一序列——
与 §4 问题 2（评分函数事后命名）是同一类偷渡。

**结论。** D1–D3 把“大脑用哪一种机制”变成一个可操作的问题：
先固定组合代数与预测动力学（作为模型类的明确承诺），
再用支持集与频率分布检验。三者不必互斥；
D2 的实例表明它们可以在不同条件下分别占优。

## 8. 第一个最小实验（模拟，非脑电）

比较三个模型（同一任务、同一数据）：

| 模型 | 机制 | 核心问题 |
|---|---|---|
| M0 | 直接状态转移 S_{t+1} = F(S_t) | 当前状态直接决定下一状态 |
| M1 | 候选生成 + 竞争选择 | 多个候选竞争产生下一状态 |
| M2 | 候选生成 + 竞争 + 状态反馈 | 新状态改变下一轮生成机制 |

比较：下一状态预测误差、状态转移熵、思维序列连续性、
对目标变化的适应速度、对随机扰动的稳定性、历史依赖程度。

**统计陷阱（必须事先防范）：** M2 参数更多，预测更好可能只是
模型复杂度带来的。须参数匹配、留出测试集、复杂度惩罚。
若 M2 在相同模型容量下仍有稳定优势，才值得继续研究反馈机制
的必要性；若 M0 已足够，就没有理由坚持三阶段模型。

## 9. 与 FECG 现有理论的关系（组织结构，非已证明的理论关系）

- FECG：动力学与能量基础（状态、转移、能量、稳定性）。
- FECG-ST：思维状态转移（S_t → S_{t+1}，本分支）。
- FECG-PD：预测动力学（Ŝ_{t+1}，系统如何提前预测下一思绪）。
- FECG-CC：概念形成与稳定（S/~，稳定预测结构何时形成概念）。
- FECG-ML：记忆与历史更新（M_t → M_{t+1}）。

FECG-ST 与 FECG-PD 须区分：前者研究下一思绪**实际**如何形成，
后者研究系统如何**提前预测**下一思绪。两者不能混为一谈。
